# Security Policy

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities through GitHub issues.

If you discover a potential security vulnerability, report it privately through GitHub's security reporting features when available.

Include enough information to reproduce and understand the issue, such as:

- affected Fastisan version or commit;
- description of the vulnerability;
- reproduction steps;
- potential impact;
- suggested mitigation, if known.

Please avoid including sensitive information that is not necessary to investigate the report.

Security reports will be reviewed as soon as reasonably possible.
